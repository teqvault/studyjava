Module 01

Product Definition

A shippable project starts with a clear user, problem, promise, and success criteria.

🚀 Definition pieces
  • Who is it for?
  • What problem does it solve?
  • What must it do on day one?
  • What is intentionally out of scope?

Module 02

Bill of Materials & Cost

Learners create a bill of materials so a project can be rebuilt, priced, and improved.

🚀 BOM fields
  • Part name.
  • Quantity.
  • Purpose.
  • Estimated cost.
  • Supplier or search term.
  • Substitute options.
🧪 Lab: Create a BOM

Make a BOM for one previous capstone and calculate approximate total cost.

Module 03

Enclosure & Physical Design

A project becomes more real when wiring, power, ports, airflow, and mounting are considered.

🚀 Physical concerns
  • Cable strain relief.
  • Access to power and reset.
  • Ventilation and heat.
  • Sensor exposure.
  • Mounting holes or adhesive plan.
🧪 Lab: Paper Enclosure Plan

Sketch an enclosure layout showing board, power, ports, sensors, and airflow.

🧠 Quick Check
Why plan sensor placement?
Module 04

Installation & Onboarding

The first-run experience matters. Learners design setup steps, defaults, and recovery paths.

🚀 Onboarding flow
  • Unbox or clone repo.
  • Install dependencies.
  • Create config file.
  • Run first test.
  • Start service.
  • Verify dashboard.
🧪 Lab: First-Run Checklist

Write a setup checklist for a fresh machine and test it from a clean folder.

Documentation & README

🚀 README sections
  • Overview.
  • Hardware list.
  • Wiring table.
  • Install steps.
  • Usage.
  • Troubleshooting.
  • Known limitations.

Module 06

Testing & Troubleshooting

Learners create a test plan instead of relying on vibes. Each important feature gets a pass/fail check.

🚀 Test plan types
  • Power-on test.
  • Sensor test.
  • Network test.
  • Service restart test.
  • Failure recovery test.
  • User demo test.

🚀 Release assets
