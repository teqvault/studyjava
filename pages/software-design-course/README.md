# TeqVault Study - Software Design & Principles Full Static Course

This is the fuller static version of the course. It is plain HTML, CSS, and JavaScript.

## How to use

Open `index.html` directly in a browser, or upload the whole folder to your site.

Suggested path:

```txt
teqvault.study/software-design/
```

## Files

```txt
index.html
syllabus.html
labs.html
quizzes.html
capstone.html
instructor-guide.html
lessons/week-01.html ... lessons/week-14.html
css/style.css
js/app.js
downloads/course-summary.txt
```

## Features

- 14 full lesson pages
- Lecture notes for every week
- Worked examples with before/after code
- Lab steps and deliverables
- Weekly assignments
- Discussion prompts
- 70 quiz questions with instant feedback
- Capstone project handbook
- Instructor guide and grading notes
- Local progress tracking
- Local student notes
- Print-friendly styling
- No npm, no build tools, no framework

## Important

Keep the folder structure intact. The lesson pages use relative links to `../css/style.css` and `../js/app.js`.

## Premium interaction features

- Saved quiz attempts and quiz average
- XP system
- Seven unlockable badges
- Student dashboard
- Code-smell diagnosis challenges
- Saved capstone milestone tracker
- Printable completion certificate
